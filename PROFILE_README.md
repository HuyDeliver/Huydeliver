## About me

I'm building hands-on experience in software testing and test automation. My graduation project focuses on automating OrangeHRM with reusable UI components, data-driven tests, and readable reports.

- 🧪 UI automation with **Java, Selenium WebDriver, and TestNG**
- 📊 Test data with **Apache POI** and result reporting with **Allure**
- 🐳 Running the demo application with **Docker Compose**
- 🔌 Currently expanding the project with **REST API testing using Rest Assured**

## Featured project

### [OrangeHRM Automation Testing](https://github.com/HuyDeliver/HuyDeliver-OrangeHRM-AutomationTesting)

An automation testing framework for a self-hosted OrangeHRM demo. The UI suite covers Login, Admin, PIM, Recruitment, My Info, and Performance, using Page Objects, shared components, Excel data providers, and failure screenshots in Allure.
